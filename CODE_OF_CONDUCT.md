# Code of conduct

## The short version

Be decent to people. Discuss the code, not the person who wrote it.

## What is expected

- Keep criticism about the work: what it does, what it costs, where it breaks.
- Assume the other person is trying to build something good, and ask before
  concluding otherwise.
- Accept that a maintained project says no to most proposals, and that a no is
  about scope rather than about you.

## What is not acceptable

Harassment, personal attacks, discrimination, unwelcome sexual attention,
publishing others' private information, and sustained disruption of discussion.

## Reporting

Report a problem to the maintainer through a
[private security advisory](https://github.com/KazKozDev/prompt-selector/security/advisories/new),
which is the only private channel this repository has. Reports are read by the
maintainer alone.

This project is maintained by one person, so enforcement is what one person can
do: edit or remove comments, close threads, and block accounts. Expect a reply
within a week.

## Scope

This applies in the repository — issues, pull requests, discussions, commits —
and anywhere someone is representing the project.

For anything this document does not cover, the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
is the reference.
